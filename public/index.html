    Espaçamento

    Use quantas chaves quiser. Se uma atingir o limite, o app troca sozinho. Chaves gratuitas: Groq, OpenRouter e Gemini.

    Ficam salvas só neste aparelho. Se o servidor já tem chaves no .env, deixe vazio.

    Quando preenchido, substitui o comportamento da persona escolhida.

    A conversa anterior continua no histórico, com a memória do caso. A nova mantém a persona que você estava usando.

    Arquitetura privacy-first. Suas pastas e notas de casos ficam salvas localmente neste dispositivo (localStorage) e não são armazenadas em banco de dados no servidor. O texto de cada mensagem passa pelo provedor de IA escolhido só para gerar a resposta.

    Backup local (JSON)

    Exporta conversas, memórias fixas, termos ocultos e resumos deste aparelho. Chaves de API não entram no arquivo. Guarde-o em local seguro: ele contém dados clínicos.

    Importar mescla com o que já existe: nada é apagado. Se a mesma conversa existir nos dois, fica a versão mais recente.

    Métricas do Klimbo

    Somente totais agregados. Nenhuma conversa, nota ou perfil individual é lido.
